# Northstar brand guidelines

- Never use superlatives such as “best”, “world’s best”, “unbeatable” or “#1” unless an approved source explicitly supports them.
- Do not use “guaranteed” without a legal-approved source.
- Write the product name as “Northstar Brew” on first mention.
- Use plain, factual language. Avoid hype and absolute claims.
- Every performance claim must match the approved product facts.
- Do not add health, safety or environmental claims that are not in the approved facts.
- Use sentence case for headlines.
